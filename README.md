# 가은의 역사 수행평가 연습

초등학교 5학년 사회 교과서의 삼국시대와 고려 내용을 복습하는 앱입니다.

- **삼국시대 탭**: 교과서 32~49쪽. 삼국, 가야, 통일신라, 발해
- **고려 탭**: 교과서 52~67쪽. 건국과 발전, 대외 교류, 사회와 생활, 불교와 문화유산

- 난이도 3단계, 시험마다 20문항
- 객관식, 주관식, 교과서 사진 문제
- 사진 문제는 모든 단계에서 이름을 직접 입력합니다. 고려청자는 ‘청자 어룡형 주전자’처럼 교과서의 구체적인 이름을 쓰며 띄어쓰기는 무시합니다.
- 제출 후 자동 채점, 풀이 해설, 교과서 쪽수 안내
- 영역별 점수와 틀린 문제 복습
- 이전 시험 문제를 우선 제외해 새 문제 조합 출제

## 실행

`dist/index.html`을 브라우저에서 열거나 정적 웹 서버의 루트를 `dist`로 설정합니다. 별도 API 키나 데이터베이스가 필요하지 않습니다.

## 확인

Node.js에서 `npm test`를 실행하면 문항 수, 유형·영역 배분, 중복 방지, 사진 파일, 주관식 채점을 확인합니다.

`npm install` 후 Chrome이 설치된 환경에서 `npm run test:ui`를 실행하면 단원 선택, 20문항 풀이와 채점, 재시험, 단원 간 답안 분리, 키보드 탭 전환, 모바일 화면을 확인합니다. 브라우저 검증은 임시 로컬 서버를 열고 완료 후 닫습니다.

## Vercel

GitHub 저장소를 연결하고 출력 폴더를 `dist`로 설정합니다. `vercel.json`에 정적 사이트 설정이 포함되어 있습니다.
